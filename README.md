# GridHeroWeekly

Archive of standalone HTML reports for the GridHero (格子大师) weekly contest.

Each report is a self-contained HTML file. Download it and open it in a browser; it needs no server or external assets. When a revision is available, the original remains linked for comparison.

## Layout

```
reports/YYYY-Www.html           original weekly report (standalone HTML)
reports/YYYY-Www-vN.html        report revision, when one was published
reports/YYYY-Www-summary.md     short run summary, when one was archived
```

`YYYY` is the contest year and `ww` is the contest week number, zero-padded to two digits. Week 46 of 2026 is `2026-W46`, matching the site ledger `year2026/week46`.
