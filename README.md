# GridHeroWeekly

Archive of standalone HTML reports for the GridHero (格子大师) weekly contest.

Each week is one self-contained HTML file. Open it in a browser; it needs no server and no external assets.

## Layout

```
reports/YYYY-Www.html           weekly report (standalone HTML)
reports/YYYY-Www-summary.md     short run summary, when one was archived
```

`YYYY` is the contest year and `ww` is the contest week number, zero-padded to two digits. Week 46 of 2026 is `2026-W46`, matching the site ledger `year2026/week46`.
